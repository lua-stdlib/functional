Module std.functional.init

Functional programming.

A selection of higher-order functions to enable a functional style of programming in Lua.

Load this module with require 'std.functional.init'. When lua-stdlib is installed, require 'std.functional' loads the older, incompatible 41.x API that it keeps under that name, and only gives you this module when lua-stdlib is not installed.

Functions that iterate take their data first and their function last, as table.sort and string.gsub do. The data is an iterable: a table, whose items are its values from 1 to its n field or length, so table.pack keeps holes; or an iterator function, whose items end with its first nil result, such as s:gmatch(pat). Use iter to pass a stateless iterator, such as iter(pairs(t)). The function is called with all the results of an iteration. Functions that return several items return lists, with their length in field n.

Each function documents its calling convention as a Signature, in the syntax of typecheck declarations: | separates alternative types, ? marks an argument that may be nil, [...] one that may be left out even when others follow it, <...> one that may only be left out along with every argument after it, and ... stands for any number more of the same. So foldl(table|function, [any], callable) takes an iterable, optionally an initial value, and a function, and detect(table|function, <?any>) takes an iterable, and optionally a predicate.

When an argument in [...] is left out, the arguments after it move up to take its place, so a nil passed there is a value. An argument in <...> is the last that is passed, and it can be left out, or be nil, which are not the same where nil is a value to compare with: some(t) tests for anything truthy, but some(t, nil) tests for a nil item.

A predicate is a plain function. Anything else that is passed where a predicate is wanted, a functable such as a lambda included, is a value to compare each item with, as ==. Use predicate to call a functable instead.

shape (t, dims)
Shape a table according to a list of dimensions.

Dimensions are given outermost first and items from the original list are distributed breadth first; there may be one 0 indicating an indefinite number. Hence, {0} is a flat list, {1} is a singleton, {2, 0} is a list of two lists, and {0, 2} is a list of pairs.

Algorithm: turn shape into all positive numbers, calculating the zero if necessary and making sure there is at most one; recursively walk the shape, adding empty tables until the bottom level is reached at which point add table items instead, using a counter to walk the flattened original list.

Signature:

    shape(table, table)

Parameters:

  • t table a table of elements
  • dims table table of dimensions {d1, ..., dn}

Returns:

    reshaped list

Usage:

    --> {{'a', 'b'}, {'c', 'd'}, {'e', 'f'}}
shape({'a', 'b', 'c', 'd', 'e', 'f'}, {3, 2})

predicate (x)
Make a predicate from a value, a function or a functable. A plain function is returned as is, and a lambda is unwrapped to the function inside it, so that its source string can no longer be recovered. Any other callable is wrapped in a plain function that calls it, since it may use its own table when it is called. Anything else becomes a test for equality (as ==, so honouring __eq) with it, including nil.

Functions that take a predicate, or a value to test for, treat a plain function as the predicate and everything else, a functable included, as a value, because functables in a sequence are usually data: a std.prototype object, for example, is callable. Pass predicate(functable) to use a functable as the predicate instead, and to search for a function value, use bind(operator.eq, {f}). For deep equality use bind(operator.eqv, {x}).

Signature:

    predicate(?any)

Parameters:

  • x a value, a function that tests a value, or a functable

Returns:

    function a predicate for x

Usage:

    is_five = predicate(5)
is_five(5), is_five(6) --> true, false
is_even = predicate(lambda '|e| e % 2 == 0')

keys (t)
The keys of a table. The keys are in a fixed order, so that the same table always gives the same list: numbers first, in numeric order, and then all the others by their string form, as str in std.normalize renders the keys of a table. values lists the values in the same order. Every field has a key, so the n field of a list with a length is one too: use collect to list the items of a list.

mapkeys (t, fn)
Map a function over the keys of a table. The values are kept. If fn returns nil for a key, the entry is left out, and if it returns the same key for more than one, one of them wins.

Signature:

    mapkeys(table, callable)

Parameters:

  • t table a table
  • fn function map function, called with each key

Returns:

    table

    a new table of the values of t for the results of

    *fn*

See also:

    mapvalues

Usage:

    --> {A=1, B=2}
mapkeys({a=1, b=2}, string.upper)
mapvalues (t, fn)
Map a function over the values of a table. Keys are kept. The result of fn is stored as it is, so a value can map to false; return the value itself to pass it through, and return nil to leave the key out of the result.

Signature:

    mapvalues(table, callable)

Parameters:

Returns:

    table a new table of the same keys, and the results of fn

See also:

    map

Usage:

lambda (s)
Compile a lambda string into a Lua function.

A valid lambda string takes one of the following forms:

1. `'=expression'`: equivalent to `function(...) return expression end`
1. `'|args|expression'`: equivalent to `function(args) return expression end`

The first form (starting with '=') automatically assigns the first nine arguments to parameters '_1' through '_9' for use within the expression body. The parameter '_1' is aliased to '_', and if the first non-whitespace of the whole expression is '_', then the leading '=' can be omitted.

The results are memoized, so recompiling a previously compiled lambda string is extremely fast.

Signature:

    lambda(string)

Parameters:

  • s string a lambda string

Returns:

    functable compiled lambda string, can be called like a function

Usage:

    -- The following are equivalent:
lambda '= _1 < _2'
lambda '|a,b| a<b'

Dispatch and selection

case (with, branches)
A rudimentary case statement. Select a branch by matching with against branches: first as a key, then, if with is a string, against the patterns of the {pattern, branch} pairs in the array part of branches, in order, and last, branches.default. A key counts if its branch is not nil, so a branch can be false. A pattern is anchored at both ends, and its captures, or the whole match if it has none, are passed to its branch. Integer keys share the array part with the pattern pairs, so don't use both in one table.

Signature:

    case(?any, table)

Parameters:

  • with expression to match
  • branches table map possible matches to branches

Returns:

    the branch selected, or if it is a function or functable,

    the result of calling it with *with* (or the captures of a
matching pattern); otherwise `nil`

See also:

    cond

Usage:

    return case(type(object), {
   table   = 'table',
   string  = function() return 'string' end,
   default = function(s) error('unhandled type: ' .. s) end,
})

case(arg, {
   {'%-%-(%w+)=(.*)', function(name, value) opts[name] = value end},
   {'%-(%w)', function(flag) opts[flag] = true end},
   default = function(s) files[#files + 1] = s end,
})
choose (test, consequent[, alternative])
Select one of two values by a test. Like test and consequent or alternative, except that either can be false or nil. A function or functable leg is called with test, and its result returned, but only if it is the one chosen, so pass anything with a side effect, or that is expensive or unsafe to compute, as a function. To return a function itself, wrap it in one.

Signature:

    choose(?any, ?any, )

Parameters:

  • test a value, 'truthy' or 'falsey'
  • consequent chosen if test is truthy
  • alternative chosen if it is not (optional)

Returns:

    consequent or alternative, or the result of calling it

See also:

    cond

Usage:

    --> 'yes'
choose(1 < 2, 'yes', 'no')

--> nothing is read unless the file is wanted
choose(wanted, function() return io.open(path):read('a') end)
cond (...)
A rudimentary condition-case statement. Each clause is a {test, branch} pair, and the first clause whose test is 'truthy' selects its branch, as an if/elseif chain does; use a true test for the last clause to make it the default. A test can be nil, which is 'falsey' like any other.

Signature:

    cond()

Parameters:

  • ... table clauses {test, branch} pairs

Returns:

    the branch of the first clause that passes, or if it is a

    function or functable, the result of calling it with the *test*;
otherwise `nil`

See also:

    case

Usage:

    -- recursively calculate the nth triangular number
function triangle(n)
   return cond(
      {n <= 0, 0},
      {n == 1, 1},
      {true, function() return n + triangle(n - 1) end})
end
default (x[, d])
A value, unless it is nil, then a default. Only nil is missing, so false, 0, an empty string or table, and a functable such as a lambda, which is an empty table, are all values that x can be. Use it for an optional argument. Unlike either, which is for a result that can be empty, an empty table is something.

Signature:

    default(?any, )

Parameters:

  • x a value
  • d what to return if x is nil (optional)

Returns:

    x, or d

Usage:

    cmp = default(cmp, function(a, b) return a < b end)
